Agent chat

Type a task and push Send. The agent uses a model through the lab.

When Tools on is set, the agent can read, write, and edit files in the sandbox folder. When it is clear, the agent is a plain chatbot.

Before the agent runs a shell command, it stops. Read the command. Push Approve to run it. Push Reject to stop it.

Push New session to start a new conversation. The sandbox files stay.
